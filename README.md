# HR Analytics Dashboard (Excel)

## Project Overview

This is an HR Analytics Dashboard project created using Microsoft Excel. The purpose of this project is to analyze employee data, understand workforce composition, and track employee attrition through interactive KPI cards and charts.

## Key HR Metrics

- **Total Employees:** 1,470
- **Active Employees:** 1,233
- **Employees Who Left:** 237
- **Attrition Rate:** 16.1%
- **Average Employee Age:** 36.9 years

## Dashboard Features

- Overall employee workforce summary
- Employee attrition analysis
- Department-wise attrition comparison
- Attrition analysis by age group and gender
- Job-role-wise attrition comparison
- KPI cards for quick insights
- Visual representation of HR data using charts

## Tools and Technologies Used

- Microsoft Excel
- Data Analysis
- Excel Formulas
- Charts and Visualizations
- KPI Dashboard Design
- Data Storytelling

## How to Use This Project

1. Download the Excel workbook from this repository.
2. Open the workbook in Microsoft Excel.
3. Navigate to the dashboard sheet.
4. Review the HR metrics, charts, and available filters or slicers.
5. Explore the employee data to understand workforce patterns and attrition.

## Project Objective

The objective of this project is to convert raw HR data into meaningful visual insights that help users understand workforce statistics and compare employee attrition across different categories.

## Key Learning Outcomes

- Analyzing employee data using Excel
- Creating KPI cards and charts
- Designing an HR dashboard
- Comparing attrition across departments and job roles
- Presenting data in a clear and professional format

## Important Note

The dashboard presents descriptive insights from the available employee dataset. These results do not establish the causes of employee attrition or predict future employee behavior. Ensure that no confidential or personally identifiable employee information is published.
